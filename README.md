# Калькулятор итоговой оценки

Одностраничный калькулятор итоговой оценки по дисциплине:

```
И% = Р1 × 30% + Р2 × 30% + Э × 40%
```

Считает итоговый балл, округляет его до целого, показывает цифровой эквивалент,
буквенную и традиционную оценку, подсвечивает строку в таблице и считает,
сколько нужно набрать за экзамен, чтобы выйти на 50 / 70 / 90 / 95%.
Отдельно отмечено, сохраняется ли стипендия (70% и выше).

## Локальный запуск

Просто откройте `index.html` двойным кликом — интернет и сервер не нужны.

Если нужен адрес для телефона в той же Wi-Fi-сети:

```powershell
python -m http.server 8123 --bind 0.0.0.0
```

и зайдите с телефона на `http://<IP-компьютера>:8123`.

## Публикация на GitHub Pages

1. Создайте на GitHub пустой **публичный** репозиторий, например `ocenka`.
   Не добавляйте README и .gitignore при создании.
2. В папке проекта выполните (подставьте свой ник, если он отличается от `mmuldagal`):

   ```powershell
   git remote add origin https://github.com/mmuldagal/ocenka.git
   git push -u origin main
   ```

3. В репозитории: **Settings → Pages → Build and deployment**
   → Source: **Deploy from a branch** → Branch: **main**, папка **/ (root)** → **Save**.
4. Через 1–2 минуты страница будет доступна по адресу:

   ```
   https://mmuldagal.github.io/ocenka/
   ```

## Установка на телефон (PWA)

Откройте ссылку с GitHub Pages:

- **Android / Chrome:** меню → «Установить приложение» (или «Добавить на главный экран»).
- **iPhone / Safari:** «Поделиться» → «На экран „Домой“».

После первого открытия страница работает офлайн: service worker кэширует
`index.html`, манифест и иконки.

## Обновление версии

После правок поднимите версию кэша в `sw.js` (например, `grade-calc-v2`),
иначе телефоны могут показывать старую версию из кэша.

## Структура

```
index.html                 приложение (HTML + CSS + JS в одном файле)
manifest.json              манифест PWA
sw.js                      service worker для офлайн-режима
icons/icon-192.png         иконка 192×192
icons/icon-512.png         иконка 512×512
icons/apple-touch-icon.png иконка для iOS 180×180
tools/make_icons.py        генератор иконок (без зависимостей)
```
